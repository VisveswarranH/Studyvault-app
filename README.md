# 📚 StudyVault App

**Author:** Visveswarran H  
**Created on:** 02.05.2025

---

## 🎯 AIM

To develop a local educational desktop application that allows users to organize and store study materials by subject, view files, and enjoy background music for a focused study experience.

---

## 🛠 FEATURES

- 📁 Upload and organize files into subject folders (Maths, Science, English, etc.)
- 🔎 View and access stored files directly from the app
- 🎵 Play background music while studying
- 🖱️ Button to open the file uploads folder
- 🎨 Attractive and user-friendly interface using `tkinter`

---
